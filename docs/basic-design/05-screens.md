# 5. 画面一覧

| 画面 | Route | 主な機能 |
|---|---|---|
| Chat | `/chat`（初期表示候補） | 質問入力、回答表示、Source一覧、Chunk展開、Loading・Error表示 |
| Documents | `/documents` | ファイルアップロード、文書一覧、状態表示、削除、再取り込み、状態ポーリング |
| Document Detail | `/documents/{documentId}` | 文書属性、登録日時、状態、Chunk数、エラー詳細、利用可能な場合は抽出テキスト表示 |
| Settings | `/settings` | モデル名、Chunk設定、接続先などの参照。MVPでは編集不可でもよい |

## 5.1 共通UI方針

- PCブラウザを主対象とし、主要操作はキーボードでも実行可能にする。
- API通信中は対象操作を二重送信できないようにし、進行中であることを表示する。
- `pending` / `processing` の文書が存在する間だけ、文書一覧を一定間隔でポーリングする。
- エラーはユーザーが次に取れる行動を含む簡潔なメッセージで表示する。内部例外やスタックトレースは表示しない。
- Sourceは文書名とページ番号を先に表示し、本文は必要に応じて展開する。
